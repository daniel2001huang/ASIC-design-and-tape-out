# ASIC-design-and-tape-out
OpenWatt processor ASIC implementation for TAMU course ECEN689 from specification to GDSII, including RTL design, functional verification, synthesis, floorplanning, placement, clock tree synthesis, and routing.

Lab 1 — Microwatt CPU Configuration, Verification, and Synthesis  

This lab establishes the initial Microwatt CPU design for the ASIC implementation project. It covers VHDL compilation, top-level configuration, multiplier simulation, and logic synthesis using GHDL and Yosys.
